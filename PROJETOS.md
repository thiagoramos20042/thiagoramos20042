## Como explorar

- Comece pelo README de cada projeto para conhecer o problema e localizar os arquivos principais.
- Nos notebooks, confira as fontes e os caminhos dos dados antes de executar as células.
- Aplicações e automações indicam seu ponto de entrada e as configurações necessárias.
- Trabalhos acadêmicos, protótipos e cenários hipotéticos estão identificados na documentação.
